# 24点求解器

一个基于 Python Tkinter 开发的 24 点游戏求解器，支持自动寻找所有可能的解法。

## 功能特性

- 🎯 **完整求解**：自动找出给定四个数字的所有 24 点解法
- 🧮 **表达式规范化**：自动去重，避免重复的等价表达式
- 🖥️ **图形界面**：简洁友好的 GUI 操作界面
- ⚡ **快速计算**：高效的递归搜索算法

## 使用方法

### 运行程序

```bash
python 24point.py
```

### 操作步骤

1. 在四个输入框中分别输入 1~9 的整数
2. 点击「求解」按钮开始计算
3. 查看求解结果，程序会列出所有有效的表达式

### 示例

输入：`1 2 3 4`

输出：
```
(1*2*3*4) = 24
((1+2+3)*4) = 24
...
```

## 核心算法

### 表达式树

程序使用 `ExprNode` 类表示数学表达式树：

- **叶子节点**：存储数字值
- **内部节点**：存储运算符和子节点

### 规范化处理

通过 `full_normalize` 函数对表达式进行规范化：

- **加法交换律**：`a+b+c` 统一排序为相同形式
- **乘法交换律**：`a*b*c` 统一排序为相同形式
- **减法化简**：`a-b-c` → `a-(b+c)`
- **除法化简**：`a/b/c` → `a/(b*c)`

### 搜索算法

1. 使用 `itertools.permutations` 生成数字的所有排列
2. 递归组合两个数字，尝试四种运算
3. 对每种组合结果进行规范化
4. 判断最终结果是否等于 24

## 代码结构

```
24point.py
├── ExprNode 类          # 表达式树节点
│   ├── is_leaf()        # 判断是否为叶子节点
│   └── get_numbers()    # 获取所有数字
├── full_normalize()     # 表达式规范化
├── node_to_string()     # 表达式树转字符串
├── find_all_solutions() # 查找所有解法
└── App 类               # GUI 应用
    ├── solve()          # 求解按钮事件
    ├── show_results()   # 显示结果
    └── clear()          # 清空输入
```

## 技术栈

- **语言**：Python 3.x
- **GUI**：Tkinter（内置）
- **算法**：递归搜索 + 表达式规范化
